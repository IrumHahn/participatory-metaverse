# 대화형 기획 가이드

질문은 설문 양식을 채우는 절차가 아니라 다음 설계 결정을 위한 것이다. 기존 답변을 요약해 이어가고 미정인 항목만 질문한다.

## 첫 대화 예시

“어떤 사람들이 와서 어떤 느낌을 얻으면 좋을까요? 예를 들면 퇴근 후 쉬는 직장인, 가볍게 어울리는 중장년층, 상품을 체험하는 고객이 있어요.”

“참여는 어느 정도가 좋을까요? ① 말없이 함께 머물기 ② 인사하고 간단히 주고받기 ③ 함께 작은 일을 완성하기”

장소가 없다면 위 답변을 받은 뒤 후보를 제안한다. 처음부터 공간·목표·조작·색상·서버·도메인을 한꺼번에 묻지 않는다.

## 필요한 경우의 다음 질문

- 사람들과 어떤 영향을 주고받나요? 주변 분위기가 반응 / 물건 나눔 / 공동 결과물.
- PC와 휴대폰 중 어느 쪽이 주 사용 환경인가요?
- 한 공간에 몇 명이면 좋을까요? 미정이면 8~15명 데모를 제안.
- 원하는 그림체나 유지할 캐릭터가 있나요? 참고 이미지는 분위기를 분석하되 자산 사용 권한을 추정하지 않는다.
- 기획, 로컬 데모, 공개 서비스 중 어디까지 필요한가요?
- 상업 공간이면 어떤 행동이 사업과 연결되나요? 상품 살펴보기, 체험, 상담, 구매 중 고른다. 결제는 필요할 때 별도 범위로 정한다.

## 서로 다른 콘셉트의 씨앗

| 공간 | 기본 참여 | 다른 사람의 영향 | 머물 이유 |
|---|---|---|---|
| 산골 온천 | 걷기, 입수, 인사 | 이웃의 물결과 몸의 작은 흔들림 | 물소리와 이완 동작을 보며 휴식 |
| 밤의 모닥불 | 자리 고르기, 장작 하나 넣기 | 공유 불꽃이 잠깐 밝아짐 | 함께 불을 바라보는 시간 |
| 비 오는 정류장 | 지붕 아래 이동, 인사 | 새 방문자의 발소리와 우산 물방울 | 비를 피하며 느슨하게 공존 |
| 공동 정원 | 씨앗 심기, 물 주기 | 모두에게 보이는 작은 변화 | 함께 가꾼 풍경, 돌아와 살펴보기 |
| 작은 찻집 | 자리 이동, 차 고르기, 건네기 | 잔을 받는 상대의 반응 | 대화 없이도 가능한 환대 |
| 상품 체험 마당 | 상품 가까이 가기, 사용 동작 | 함께 살펴보거나 반응하기 | 제품을 생활 맥락에서 발견 |

표의 기능은 후보이며 필수 세트가 아니다. 사용자의 콘셉트에 맞는 행동 1~3개만 고른다. 저압력 휴식 공간에 출석 보상·성장 압박을 자동으로 추가하지 않는다. 반대로 사용자가 협동 놀이를 원하면 휴식만 강요하지 않는다.

## 브리프 형식

- 한 문장 콘셉트 / 대상 / 방문 동기
- 첫 30초 / 핵심 행동 / 다른 사람의 영향 / 다시 방문하는 이유
- 정원 / 장치 / 시점·이동 / 아트와 소리
- 첫 구현 범위 / 이후 아이디어
- 검증 가능한 완료 조건 / 로컬 또는 공개 범위

예: “두 브라우저에서 한 사람이 장작을 넣으면 양쪽에 같은 불꽃 변화가 보이고, 상대는 가까이 돌아서 인사할 수 있다.”
